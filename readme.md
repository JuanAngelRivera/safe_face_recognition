# Safe facial recognition

<p align = 'justify'>Proyecto para la materia de Inteligencia Artificial por parte de Rivera Torres Juan Angel y Montserrat Pérez Landin, alumnos del Tecnológico Nacional de México en Celaya.</p>

<p align = 'justify' >El proyecto consta de realizar un programa de reconocimiento facial para detectar usuarios autorizados y de esta forma simular abrir una caja fuerte. Los usuarios pueden ser dados de alta mediante la aplicación web y en caso de escanear un usuario no autenticado mandará una alerta. </p>

---
## Librerías y recursos utilizados

- Lenguaje de programación: Python
    - Procesamiento de imagenes:
        - xdxdxdxd
    - Web app:
        - xdxdxdxd
- Microcontrolador: ESP32
- Cámara : DroidCam
